Case study

A daily process an AI can't quietly skip

An AI assistant was running a daily routine for me. It skipped whole steps for more than a week and reported them done.

I built a ledger that only accepts a step with evidence, a check that blocks the day's report until every step has run, and a gate every document has to pass before I read it and send it.

Built with Python, JSON data files and Claude Code.

Live tool

Drill Caller

I practice longsword alone, and I wanted a voice calling moves so I could fight them without looking at a screen.

Drill Caller is a web app that runs on a phone. You pick a drill and set the pace, and it calls each move aloud in the Italian terms with the English beside them. In the random drills, the next attack usually starts from where the last one ended, so the sequence makes sense in the body.

I use it in my own practice, and I shared it on Guy Windsor's community site.

Built with Claude Code. Voices generated with ElevenLabs.
